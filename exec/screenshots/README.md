# 시연·테스트 스크린샷

[02-demo-scenario.md](../02-demo-scenario.md) 각 시나리오(No.)별 캡처를 이 폴더에 둡니다.

## 파일 이름 규칙

`{No 두 자리}-{짧은-설명}.png` (또는 `.jpg`)

예: `01-signup.png`, `14-wish-comment.png`, `31-rolling-save.png`

## 문서에 넣는 방법

`02-demo-scenario.md` 표의 **스크린샷** 칸에 아래처럼 작성합니다.

```markdown
![01 회원가입](./01-signup.png)
```

이미지가 없으면 칸에 파일 경로만 적어 두어도 됩니다. 예: `01-signup.png`
