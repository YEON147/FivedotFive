# 오쩜오 — 테스트·시연 시나리오

> **기준 문서**: 팀 테스트 시나리오 CSV (39건)

본 문서는 QA·발표 시연 시 공통으로 사용하는 시나리오입니다. 각 항목은 **사전 조건 → 테스트 절차 → 테스트 데이터 → 기대 결과** 순으로 확인합니다.

**스크린샷**: [screenshots/](./screenshots/) 에 `NN-설명.png` 로 저장한 뒤, 아래 표 **스크린샷** 칸에 `![설명](./screenshots/NN-설명.png)` 형태로 삽입합니다.
